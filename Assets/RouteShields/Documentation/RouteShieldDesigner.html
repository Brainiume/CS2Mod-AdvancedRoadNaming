How to use the files

  1. Put an SVG in ModsData\AdvancedRoadNaming\RouteShields or a nested folder.
  2. Use Refresh Route Shields in the mod settings. The mod creates a matching JSON if needed.
  3. Open that JSON in this page, optionally load the SVG for a preview, and adjust the fields.
  4. Select Apply Changes to update the opened JSON file directly. Download and Copy remain available as compatibility options.
  5. Refresh shields again, then select the shield from Browse shields.

Important behavior

  • The generated id must not be changed. Moving or renaming the SVG changes its id and can disconnect saved routes.
  • Later text layers draw over earlier layers.
  • Positive X offsets move right. Positive Y offsets move down. Positive rotation is clockwise.
  • The game removes spaces and converts route codes to uppercase.
  • The in-game text uses the game UI font and shrinks to fit. This browser preview is an approximation.
  • Malformed definitions are reported in the mod settings and Player.log. The last valid loaded version remains active when possible.
  • Built-in definitions use the same schema, but mod updates can overwrite edits to bundled files.
